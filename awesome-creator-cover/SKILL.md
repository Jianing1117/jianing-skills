# 封面设计模块

封面是内容在信息流里的第一张脸。白板风格适合知识类、观点类和教程类内容：干净、有信息密度，也适合截图传播。

本 Skill 直接处理白板封面，不再经过额外的封面子路由。

## 封面专用规格

| 平台 | 推荐比例 | 说明 |
|------|---------|------|
| 小红书 | 3:4（竖版） | 信息流主流，适合图文封面 |
| 抖音 | 9:16（竖版） | 视频封面，全屏竖版 |
| 通用 | 1:1（方版） | 两个平台都能用，适合方形展示 |

封面内容要求：

- 标题必须足够大，在手机缩略图中仍然清晰。
- 最多保留 1 个核心信息和 2–3 个要点。
- 保持充足留白，不要把正文搬到封面上。

## 工作流程

### 第一步：收集封面信息

确认三件事：

1. 封面要传达的核心信息：标题、一句话结论或 2–3 个要点。
2. 目标平台：小红书、抖音，或两个都要。
3. 署名或品牌标识（可选）。

如果用户已经提供文案或脚本，直接从中提取，不要要求用户重复概括。

### 第二步：收敛文案

- 标题尽量控制在 18 个中文字以内，超出时优先改写，不是简单截断。
- 可选一行副标题，最多 28 字。
- 要点最多 3 条，每条只保留一个意思。
- 默认使用黑白主色与蓝绿点缀，不要为了“像白板”而堆满线条。

### 第三步：生成可编辑封面

使用本 Skill 内置脚本 `scripts/make_cover.py`，不依赖其他 Skill。先定位到本 Skill 目录，再运行：

```bash
python3 scripts/make_cover.py \
  --title "封面标题" \
  --subtitle "可选副标题" \
  --bullet "要点一" \
  --bullet "要点二" \
  --platform xiaohongshu \
  --output ./cover.excalidraw
```

`--platform` 支持 `xiaohongshu`、`douyin` 和 `square`；可用 `--author` 添加署名。输出路径必须由当前任务明确给出，不要硬编码桌面或用户主目录。

运行后确认文件存在、JSON 可解析，再告知用户已生成。用户可在 [Excalidraw](https://excalidraw.com) 中打开并继续编辑。

## 封面自检

1. 不看正文，能否立即理解主题？
2. 标题在手机缩略图里是否清晰？
3. 是否超过 5 行文字？超过则继续删减。
4. 截图单独传播时是否仍然成立？

如果用户还没做标题，使用 `awesome-creator-title`；还没优化开头，使用 `awesome-creator-hook`；还没优化正文，使用 `awesome-creator-content`。
