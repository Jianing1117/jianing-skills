# §1 标题

标题只干一件事：让人在 0.5 秒内判断"这个值得点开"。

工作方式是**给足候选让用户挑**，不是替用户拍板。

## 1.1 两个平台两套逻辑

| | 小红书 | 抖音 |
|---|---|---|
| 首要任务 | 关键词 SEO + 获得感 | 情绪触发 + 好奇缺口 |
| 字数 | ≤20 字（含标点，硬限制） | 无硬限，≤15 字更佳 |
| 关键词 | 前 18 字放 2 个核心词 | 不是重点 |
| 成立标准 | 看完知道能得到什么 | 看完不得不想知道结果 |

## 1.2 小红书的双标题

小红书有两个标题，服务两个完全不同的对象。

| | 封面标题 | 正文标题 |
|---|---|---|
| 读者 | **人**（刷到的用户） | **算法**（搜索 + 推荐） |
| 位置 | 封面图上的大字 | 图片下方的文字标题 |
| 字数 | 5–10 字，越短越有力 | ≤20 字 |
| 关键词 | 不强求，情绪/数字/反差优先 | 前 18 字放 2 个核心搜索词 |
| 目标 | 让眼神定住，停止滑动 | 被精准推给目标用户 |

同一条内容两个标题可以完全不同：封面写「月入 5 万！」，正文标题写「全职主妇副业变现 90 天实战经验」。一个抓眼，一个抓搜。

**抖音没有这个区分**，封面文字和发布标题走同一套情绪逻辑。

## 1.3 九种触发模式

每种模式至少给 3 个候选。**模式跟内容明显不搭就跳过**，把数量补到更合适的模式上——保证质量，不凑数。

### ① 数字结果 + 悬念反差
具体数字制造冲击，悬念勾起好奇。看到结果，不知道怎么做到的。

`[起点] + [结果数字]，[悬念/反差]`

- 我如何在 90 分钟赚到 10 万
- 全职主妇副业 90 天月入 5 万，让你想不到的秘密
- 犯了这个不同寻常的错，我反而在台上特别自信

### ② 圈定人群 + 极致结果
用身份、状态、人生节点精准圈人，同时给极致结果或消除障碍。

`[人群/状态] + [数字] + [极致结果]` · `给每个 [状态] 的人` · `不会 [障碍]，也能 [结果]`

- 给每个 35+ 职场女性的终极建议
- 25 岁还没有分文存款的人
- 不会 IT，也能几分钟搭好你的自建站

### ③ 极致情绪 + 场景共鸣
强烈普遍的情绪词直接命中特定场景下的感受。

`[情绪热词] + [具体场景/结果]`

- 月薪 3000 党哭了，这 5 个省钱技巧让我存下 2 万
- 裁员第三天，我做了这辈子最正确的决定
- 在北京租房 5 年，终于找到一个不委屈的方法

### ④ 反常识 + 反转叙事
打破已有认知，或用亲身经历制造意料之外的反转。

`[常识操作] 其实对你有害` · `为什么我不 [大多数人都在做的事]` · `[负面事件]，反而让我 [正面结果]`

- 为什么喝牛奶其实对你一点也不好？
- 为什么我不玩微信朋友圈
- 公司破产是如何带给我财富自由和内心平静的

### ⑤ 好奇缺口
暗示"有你不知道的信息"，制造信息不对称焦虑。

`[某群人] 不会告诉你的 [X]` · `关于 [话题]，你太晚知道的 [X] 个事`

- 会赚钱的博主不会告诉你的建议
- 关于互联网营销，创业者们太晚知道的 3 个教训
- 营销专家们不想要你知道的 5 件事

### ⑥ 冲突与争议
亮出有争议的立场，加明确观点，引导站队。断言和疑问句都行。

`[有争议的立场/事件] + [明确观点]`

- 裸辞会不会是你做过的最好决定？
- 停止学习！！开始实践！！
- 做微商已经过时了么？

### ⑦ 指令挑战 + 趣味性
发出邀请或挑战，激发参与感。适合打卡类、挑战类。

`敢不敢和我一起 [挑战]？` · `跟我一起 [X] 天 [做到某件事]`

- 敢不敢测一测，你的脸书主页是不是最优化的
- 至关紧要的头一分钟——如何谈判

### ⑧ 恐惧 / 损失
激活损失厌恶——不是冲着"得到"点进来，是怕"亏了/白努力了"。适合避坑类、警示类。

`[数字] 件阻碍你 [目标] 的事` · `[X] 的最根本原因`

- 3 件阻碍你 IP 变现的事
- 减肥不成功的最根本原因
- 警告！这 3 件事正让你的保湿霜涂了等于白涂

### ⑨ 权威借力
借名人/案例/数据提升可信度，让内容"不只是你说的"。

`[名人/案例] + [话题] + 帮助我 [结果]` · `最好的 [一群人] 都做了什么不同的事？`

- TONY ROBBINS 的晨间冥想帮助我保持心流状态
- 最赚钱的短线投资人都做了什么不同的事情？

## 1.4 两条硬性过滤

**张力过滤** —— 每个候选输出前自检，命中以下至少 2 项才纳入，否则重写：

> 有具体数字 · 有对比/反差 · 有悬念（没把答案说完）· 有冲突/争议 · 有时间承诺 · 有结果承诺

**普世化** —— 用大众说得出口的词替换行业术语。用词越具体普通，能推到的流量池越大。

| 行业黑话 | 普世说法 |
|---|---|
| 知识付费 / 引流款 / 自媒体 | 赚钱 / 涨粉 / 不上班 |
| 财务自由 | 不上班 |
| 消费型兴趣 | 靠兴趣赚不到钱 |

## 1.5 输出格式

```
## 正文标题候选（给算法看）
### [模式名]
**[标题]**
→ [一句话说明为什么这个角度有效]

## 封面标题候选（给人看）· 小红书专属
**[5–10 字]** → [说明情绪/反差/数字的使用]

## 重点推荐
正文标题 3 个 + 封面标题 3 个，各附一句理由
```

推荐从候选里挑张力最强、最符合平台逻辑的，**说清理由，不替用户做最终决定**。

# §2 开头

短视频前 3 秒是生死线。开头唯一任务：**让人不划走**。

## 2.1 好开头的三个要素

```
好开头 = 话题 + Hook + 可信度
```

- **话题**：我在讲什么。**不能假设用户看了标题**，开头必须独立工作
- **Hook**：为什么要继续看。数字/反差/悬念/情绪
- **可信度**：为什么要信你。做到过的成果、亲历的案例、研究过的数据

拼起来：「我去年涨粉 200 万（可信度+Hook），靠的就是搞清楚选题和标题的区别（话题）」

**核心原则：开头不说答案。** 把方向点出来，结论留在后面——有悬念才有人看到最后。

## 2.2 最大公约数原则

生成之前先问：这个话题用最普通的语言说，能吸引多大的人群？

| 窄 | 宽 |
|---|---|
| 做内容创业的人 | 想靠兴趣赚钱的人 |
| 学 AI 提效的人 | 想少加班的人 |
| 研究理财的人 | 不想再为钱焦虑的人 |

同样的内容换一个更普世的框架，覆盖面可以差 10 倍。

## 2.3 三种生成方法

总共出 **10–15 条**，每种方法 3–5 条。

**口播硬性条件**：所有候选必须能流畅说出来。书面语、自问自答（「你有没有想过…其实…」）、绕口长句——直接重写，不输出。

### 方法一 · 素材提取

从用户给的内容里找素材，按优先级用：

| 素材类型 | 优先级 | 怎么判断 |
|---|---|---|
| 晒结果 + 反转 | ⭐⭐⭐⭐⭐ | 有具体成果，且背后方法出乎意料 |
| 数字冲击 | ⭐⭐⭐⭐ | 大数字、时间压缩、对比数字 |
| 反差 / 转变 | ⭐⭐⭐⭐ | 之前 vs 之后，差距越大越好 |
| 金句 | ⭐⭐⭐ | 能独立成立、有记忆点 |
| 权威 / 案例 | ⭐⭐⭐ | 名人、知名品牌、行业数据 |
| 痛点共鸣 | ⭐⭐⭐ | 目标人群说得出口的真实焦虑 |

某类素材完全没有就跳过，数量补到有素材的类型上。

最高优先级示例：
> 「我在过去一个月涨粉了两万多——很多人问我怎么做到的，其实我只是做好了这一件事」
> 可信度（两万多）+ 悬念（一件事），同时成立

### 方法二 · 素材增补

**第一步：话题普世化检查。** 有时换框架比补素材更有效。

**第二步：向用户提问。** 列出六类素材问有没有：

1. **数字**：有没有意想不到的数字？
2. **成果**：你或你见过的人，做到过什么具体结果？
3. **转变**：有没有明显的"之前 vs 之后"？
4. **金句**：有没有一句话特别有道理、值得记住？
5. **权威**：有没有名人/品牌/数据可以引用？
6. **痛点**：目标用户现在最焦虑的一件事，用他们的话说出来？

**都给不出来时**：基于话题方向主动补充合理数据或案例，输出时**必须注明「这是补充的素材，建议替换成你自己的真实数据」**。

### 方法三 · 悬念制造

直接根据主题或标题生成，不需要用户填空。

**好奇缺口**（2–3 条）——提一个答案不明显的问题，不给答案。
> 善良的李亚鹏，认识半个娱乐圈，30 年为什么赚不到钱？
> 一个月存 3000 块，10 年后到底有多少？大多数人算错了

**反常识**（2–3 条）——先说违反直觉的结论，然后停下。
> 努力工作，是很多人一直穷下去的核心原因
> 一个人赚不到钱，是因为你上班上多了

**争议立场**（1–2 条）——亮出会让人想反驳或站队的观点。
> 副业这件事，我越来越觉得大多数人根本不应该做
> 裸辞，是我这辈子做过的最正确的决定

## 2.4 输出格式

三种方法分组列出，每条附一句"用了什么素材/为什么有效"，最后给 **Top 3 推荐**（张力最强 + 口播最自然），附理由。

# §3 正文结构

## 3.1 五种内容类型与结构原型

| 类型 | 结构原型 | 常见塌陷处 |
|---|---|---|
| **观点型** | 结论先行 → 拆解论据 → 案例验证 → 一句话收尾 | 先铺垫太久才说结论 |
| **教程型** | 痛点共鸣 → 分步展开 → 避坑提醒 → 效果预期 | 步骤太密集、没有喘息 |
| **故事型** | 场景代入 → 冲突/困境 → 转折点 → 结果/感悟 | 冲突不够强，感悟太说教 |
| **清单型** | 痛点引入 → 逐条展开（每条带小钩子）→ 汇总提炼 | 后半段草草收场 |
| **对比型** | 常见做法 → 为什么不行 → 正确做法 → 对比结果 | 「为什么不行」解释太弱 |

先认出属于哪种类型，再对照原型补齐缺失的环节。

# §4 互动钩子

## 4.1 平台权重

| 钩子 | 标注 | 小红书 | 抖音 |
|---|---|---|---|
| 完播 | `【完播钩子】` | ★★★ | ★★★★★ |
| 点赞 | `【点赞钩子】` | ★★ | ★★★★ |
| 收藏 | `【收藏钩子】` | ★★★★★ | ★★ |
| 评论 | `【评论钩子】` | ★★★★ | ★★★ |
| 转发 | `【转发钩子】` | ★★ | ★★★ |

- **只发小红书**：重点加收藏 + 评论
- **只发抖音**：重点加完播，点赞每段必有，评论结尾一个
- **双平台**：五种都考虑，收藏和完播都要照顾

## 4.2 五种钩子

### 【完播钩子】
每 15–30 秒给一个继续看的理由。**放在段落过渡处**，不要放在一段话中间。

- 悬念预告：「但还有一个更关键的点，很多人没注意到」
- 数字倒计：「第 3 个方法才是我压箱底的，先说前两个」
- 转折提示：「等一下，这里有个反直觉的东西」
- 时间锚定：「下一分钟是整条视频最重要的部分」

节奏要自然，像说话一样带过，不要堆砌。

### 【点赞钩子】
点赞来自情绪共鸣——"说出了我的心声""这句话太准了"。

- 金句：高度浓缩、能独立成立、有记忆点
- 情绪共鸣：把用户想说但说不出来的话说出来
- 身份认同：「如果你也是 XXX 类型的人，你一定懂这种感觉」

**位置**：开头和结尾必须有；每个核心观点讲完跟一句。

### 【收藏钩子】
用户收藏的是"以后用得到"的东西，**必须是可以直接用的结构化内容**。

**插入前先整理内容**：清单 → 统一格式，每条可扫读（编号 + 一句话）；步骤 → 动词开头，边界清晰；框架 → 考虑表格化。

- 截图提示：「建议截图保存这张清单」
- 资源自然提及：「我把这套方法整理成了一份模板，放在主页合集里了」（**只提存在，不要求用户做任何事**）
- 价值宣告：「这 5 个步骤我自己用了一年，整理在这里了」

### 【转发钩子】
用户转发，是因为这条帮他表达了想说的话，或他觉得某个朋友需要看到。

- 帮用户表达：一句金句，看完觉得"这就是我想说的"
- 送给别人：「发给你身边正在 XXX 的朋友」

**位置**：结尾，或一个特别有共鸣的金句之后。**可以和收藏钩子放在一起**——收藏是给自己留，转发是送给别人，两个动作能同时触发。

### 【评论钩子】
每篇 1–2 个中间 + 1 个结尾。

| 类型 | 模板 | 示例 |
|---|---|---|
| 开放问题（结尾必有） | 真实的、和内容相关的提问 | 「你现在最卡在哪一步？评论区说说」 |
| 站队 | 「你是 A 还是 B？」 | 「你觉得你是执行型还是想太多型？」 |
| 选择题 | 「打 1/2/3」 | 「你卡在哪？1.不知从哪开始 2.开始了做不下去 3.做完了没人看」 |
| 自测 | 「你有没有过……？」 | 「你有没有发过一条数据好、但下一条不知道发啥的视频？」 |
| 挑战 | 「试试看：……」 | 「现在就想一下：你上一条视频，真正帮到了谁？」 |

## 4.3 钩子标注格式

嵌在正文里，用引用块：

```
……第二段内容……

> 【完播钩子】但接下来这个才是关键，先把这个搞清楚

……第三段……
```

用户给了文件路径时，在**同一文件夹**下新建 `[原文件名]-v2.md`，**不改原文件**，文件头写明平台、结构改动、钩子数量统计。

# §5 切片：长内容 → 短内容

一支 5–10 分钟的中长视频，切出 **3–5 条能独立成立的判断**，每条写成 60 秒口播。

## 5.1 判断 ≠ 步骤（切片唯一的难点）

| | 例子 | 能切吗 |
|---|---|---|
| 步骤 | 「第三步点这个按钮，然后建一个文件夹」 | ❌ 脱离上下文是废话 |
| 判断 | 「大多数人搭知识库失败，不是工具不好用，是一开始就想搭个完美结构」 | ✅ 独立成立、有反直觉内核 |

**三条筛选标准，缺一不可**：

1. **能脱离上下文** —— 不需要前文就成立
2. **有反直觉内核** —— 听完有"咦"的感觉，不是常识复述
3. **是用户自己的判断** —— 不是通用道理

## 5.2 60 秒骨架

用口播观点公式：**具体现象 → 反直觉判断 → 人生落点**。**永不从抽象问题开头。**

```
0–5s    具体现象（有画面感，不是抽象提问）
5–15s   反直觉判断（这一句要能截图）
15–45s  一个例子或一层推演
45–60s  人生落点 + slogan / 仪式句
```

## 5.3 每条切片的输出

60 秒口播稿 · 可截图的那一句 · 归属版面 · 建议出口（短视频 / 图文 / X 碎片）· 四问自检结果

# §6 合规红线

| | 内容 | 原因 |
|---|---|---|
| ❌ | 「评论领资料」「扣 1 扣 2」 | 诱导互动，平台违规 |
| ❌ | 「私信我领取」 | 引导私信导流，违规 |
| ❌ | 「点赞收藏评论三连」 | 多重利益交换，严重违规 |
| ✅ | 问真实问题 | 自然对话，不涉及利益交换 |
| ✅ | 提自己有资源 | 只提存在，不要求用户做任何事 |
| ✅ | 挑战 / 自测 | 用户自愿参与 |

平台合规红线之外，还有**用户自己的一票否决清单**（在其知识库的宪法层里）——那部分由诊断段负责扫，不在这里复述。
