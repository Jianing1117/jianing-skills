# 爆款 Playbook

> 内容引擎的**方法论层**。所有规律都是从真实爆款拆解里提炼出来的，每一条都能追溯到证据。
>
> **收录边界**：只收「不特定于某个账号」的通用规律。个人判准——定位、人格边界、slogan、四问的具体内容、经营数字——一律不进本文件，它们留在各自的知识库里，由引擎运行时读取。
>
> 这条边界决定了本文件可以公开：**形可以写在这里，神留在人身上。**

---

## 0. 收录纪律

### 条目格式（不符合格式的不收）

```markdown
### [规律，一句话说完]
- **机制**：为什么这样有效——讲人的反应，不讲平台参数
- **置信度**：参考 / 已印证 / 自家验证
- **边界**：什么情况下不成立
- **证据**：
  - [链接] · 粉X 赞X · 赞粉比 X 倍 · [它在这条规律上具体做了什么]
  - [链接] · 粉X 赞X · 赞粉比 X 倍 · [...]
```

拆解卡不落盘，**证据行就是唯一留存的证据**。所以证据行必须自带信息量——写"开头很吸引人"等于没写，要写"第一句直接抛结论，零自我介绍"。

### 置信度四档

| 档位 | 条件 | 能不能用 |
|---|---|---|
| **参考** | 1 条证据 | 收进来并标注，**只作参考，不作依据** |
| **已印证** | ≥2 条**独立**证据 | 可以当依据引用 |
| **自家验证** | 自己发内容验证过 | 优先用 |

被推翻的条目**不删**——加一行 `❌ 已推翻（日期·原因）`，正文划掉。反面教材和正面规律一样值钱。

### 三条铁律

1. **说不出证据的条目，是编的，删掉。** 每条至少挂一行证据。
2. **冲突不覆盖。** 新规律和老规律打架 → 两条并列，都标"待验证"，等数据裁决。方法论允许自相矛盾一段时间，不允许假装没矛盾。
3. **脱敏。** 真实经营数字、客户信息、未公开的个人经历，一律不进。数字改成量级或比率区间。

## 9. 平台差异（存量基线）

> 来源：公开存量知识，非拆解所得。作为对照基线使用，被拆解卡推翻时以卡片为准。

| 维度 | 小红书 | 抖音 |
|---|---|---|
| 流量来源 | 搜索 + 推荐并重（搜索占比高） | 推荐流为主 |
| 内容形态 | 图文为主，短视频为辅 | 短视频为主 |
| 用户心态 | 主动搜索、收藏备查 | 被动刷到、即时消费 |
| 爆款核心 | 信息密度 + 关键词 SEO | 前 3 秒完播 + 情绪张力 |
| 互动权重 | 收藏 > 评论 > 点赞 | 完播 > 点赞 > 评论 |
| 生命周期 | 长，可被搜索反复触达 | 短，48 小时内定生死 |
| 标题字数 | ≤20 字（硬限制） | 无硬限，≤15 字更佳 |

**小红书双标题**：封面标题给人看（5–10 字，情绪/数字/反差优先），正文标题给算法看（≤20 字，前 18 字放 2 个搜索词）。同一条内容两个标题可以完全不同。抖音无此区分。

**跨平台迁移**：小红书图文 → 抖音口播，重写开头，信息密度换成情绪张力；抖音视频 → 小红书图文，补关键词规划和可收藏的结构化干货。
