# 2D Content Illustrations

## Formula

```text
confirmed 2D personal IP + one original metaphor + one core action + short labels + whitespace
```

## Visual rules

- Default to a 16:9 white canvas; keep the subject near 40%-60% and at least 35% quiet space.
- Keep character, objects, and annotations in the approved 2D line/fill/watercolor language.
- Use 2-5 short Chinese labels and sparse accents from the IP palette.
- The IP must perform the core action. If removing the character leaves the metaphor intact, redesign the action.
- Avoid 3D material, photographed objects, generic mascots, commercial vector posters, children's art, PPT/flowchart layouts, dense text, and reused case compositions.

## Content design

Turn the core idea into a physical verb such as pull, sort, block, weigh, fold, connect, open, press, or recycle. Pair it with one or two familiar low-tech objects.

Choose one composition: flow, system fragment, before/after, character states, single metaphor, layered method, route, or 2-4 panel comic. Rebuild the object, action, spatial relation, and labels from the current content.

For a shot list, include only placement, core idea, metaphor, character action, main object, short labels, and a three-second reading.

## Prompt requirements

Every image prompt must include:

- Confirmed reference image, identity anchors, and approved 2D render rules.
- One theme, one metaphor, one character action, one or two objects, and exact short labels.
- White canvas, whitespace target, restrained IP palette, and explicit bans on identity drift and 3D rendering.

Use the complete template in `prompt-2d.md` when generating, especially with weaker models.

## QA

Check only: same person, same 2D family, character-led action, one readable idea, clean whitespace, and short legible labels. Fix one variable at a time: identity, action, density, or text.
