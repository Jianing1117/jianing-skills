# 2D Image Prompt

Read only when generating `flat-2d` content illustrations. Replace every variable and attach the matching confirmed character image.

```text
Generate one standalone 16:9 horizontal Chinese article illustration.

CONFIRMED PERSONAL IP
Use the character in {reference_asset}. Preserve the same identity in every image:
- hair: {hair}
- face and age impression: {face}
- skin: {skin}
- standard outfit: {outfit}
- signature accessories: {accessories}
- temperament: {temperament}

APPROVED 2D RENDERING
{line_style}. {fill_or_watercolor_style}. {drawn_shading}. Use {palette} as sparse accents.
Keep the character, objects, and annotations in one coherent flat 2D illustration language.

CONTENT
Theme: {theme}
Core idea: {one_sentence_core_idea}
Visual metaphor: {one_physical_metaphor}
Character action: {exact_action_and_relationship_to_object}
Main objects: {one_or_two_objects}
Chinese labels: {two_to_five_exact_short_labels}

COMPOSITION
Pure white background. Main subject occupies about 40%-60% of the canvas. Preserve at least 35% quiet white space. One image explains one idea. The personal IP performs the core action; it is not a decorative mascot.

AVOID
Do not change the face, hair, outfit, accessories, palette, or age impression. No 3D material, realistic studio lighting, photographed objects, generic mascot, famous-character imitation, extra people, logo, watermark, gradient, paper texture, complex background, commercial vector poster, children's illustration, PPT infographic, formal flowchart, dense text, top-left type title, or reused old-case composition.
```
