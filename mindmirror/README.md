# 观自在 · MindMirror

> 不要从工具开始，从自己开始。
>
> 一个开放的 Agent 技能包：把你写下的生活——日记、笔记、项目痕迹——变成一份有证据、有置信度、可持续迭代的自我认知档案。
> 纯 Markdown 实现，无依赖——Claude Code、Codex、WorkBuddy 或任何能读文件的 AI 助理都能运行。

三种模式，回答关于"我"的三类问题：

| 模式 | 回答的问题 | 方法 |
|---|---|---|
| **照见**（快照式） | 我到底是谁？我在骗自己什么？ | 22 个自我认知问题，每答带证据引用与置信度评分，敢下判断但可反驳 |
| **数字分身**（深访式） | 我是什么风格、偏好、模式？ | AI 从语料起草十维度画像，你只做校准——可导出为系统提示或个人上下文文件包 |
| **人生规划** | 我该往哪走？怎么验证？ | 三条五年剧本 → 路线图 → 得失对比 → 90 天低成本实验 |

产出统一存进**观自在**目录——一套活的自我认知档案：每次运行是"更新"而非新报告，重跑会得到**变化报告**（哪些结论在松动、哪些置信度升降）。它也是其他 AI「了解你」的标准入口：想让 ChatGPT 或任何 agent 懂你，把校准过的分享版喂给它即可。

## 为什么它不一样

- **读语料，不发问卷**：它不问"你觉得自己是什么样的人"——它读你写下的生活。**日记里的你，比问卷里的你诚实得多**；没有笔记的用户走温和的访谈路径，聊出来的内容就是语料
- **给证据，不给话术**：没有星座式人格标签。每条结论标注证据出处和置信度（1–10），7 分以上必须有两个独立事件簇支撑，引号里只允许出现逐字核验过的你的原文——**结论的价值在于证据可追溯，不在于是否刺痛**
- **建档案，不出报告**：产出是可持续迭代的活文件，重跑得到"我变了什么"的变化报告；数字分身可导出为系统提示或「使命/目标/项目」式的个人上下文文件包——想写"我的人生使命"却对着空白文件发呆的人，可以让它从你的语料里长出初稿

## 安装

```bash
git clone https://github.com/Jianing1117/mindmirror.git
```

技能就是 `mindmirror/` 目录下的 4 个 Markdown 文件（SKILL.md + 三个模式指引），没有代码依赖：

- **Claude Code / Cowork**：`cp -r mindmirror/mindmirror ~/.claude/skills/`
- **Codex 及其他 CLI agents**：把 `mindmirror/` 放进它的技能目录，或在 AGENTS.md / 自定义指令中引用 SKILL.md
- **网页对话类（Claude.ai、ChatGPT 等）**：压缩为 zip 上传技能，或直接把 SKILL.md（加上要用的模式指引）粘贴为对话的开场指令——没有文件系统时改用上传材料或访谈路径

## 使用

对你的 AI 说：

- 「**自省**」或「/mindmirror」——照见完整版（22 题）
- 「**快速版自省**」——只答 5 题（盲点/情绪习惯/核心矛盾/最大赌注/综合），语料减半
- 「**给我做数字分身**」——十维度画像，起草后你校准（可以语音说）
- 「**帮我规划人生**」——五年剧本推演 + 90 天实验
- 没有日记和笔记？直接说「数字分身」——转入温和的访谈路径，聊出来的内容就是语料

流程上你会遇到几个停顿点，它们是有意设计的：**授权确认**（读哪些材料、写到哪里，读之前先问你）、**主线检查点**（正式分析前先给你看"我从哪些线索出发"，此时纠正最便宜）、**校准**（画像交付后，你的每条纠正都会修订档案）。

## 它的自我约束

这不是占卜，也不是心理咨询。Skill 内置了一套认识论和安全纪律：

- **认识论三条**：结论只来自实际读到的语料；每题前提都可能不成立（"此题不适用于你"是合格答案）；**你的不同意永远不构成"防御"的证据**——只会让结论降级或撤回
- **三本账**：你说的（陈述）、你做的（行动）、你所处的（约束）分开记账，不一致只生成待检验假设，不断言"言行不一"
- **置信度硬上限**：内在动机类无自述支持 ≤6 分；"别人怎么看你"无外部反馈 ≤5 分；未来预测 ≤6 分；≤6 一律当假设
- **授权先行**：读任何内容之前先枚举清单、确认范围；凭证/证件/财务资料永不读取，任何授权都不覆盖
- **危机优先**：分析前先做近期安全预扫，发现急性心理危机迹象即暂停一切分析，优先引导求助
- **隐私分区**：照见、访谈记录、底稿默认私密；对外只通过脱敏、经确认的 `分享/`；AI 自己的产出永久排除于语料，不会"自我印证"

## 隐私

本 Skill 不额外调用任何第三方网络服务；你的语料和产出按你所用 AI 产品与账户的数据政策处理。观自在档案存在你自己的目录里——注意：若目录在云同步盘或 Git 仓库内，"私密"只是目录约定。
