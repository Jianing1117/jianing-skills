## Phase 0: 项目初始化

**触发时机：** Skill 启动时立即执行，在任何内容研究之前

**目标：建立项目文件夹结构，让用户有明确的素材投放点**

`PROJECT_DIR` 已由主 `SKILL.md` 确定。本文所有相对路径都以它为根；不要自动写入桌面或用户主目录。

### Step 0.1: 创建项目文件夹

**在开始任何工作之前，先创建项目文件夹结构：**

```bash
mkdir -p "$PROJECT_DIR/assets"
mkdir -p "$PROJECT_DIR/.slide-design/charts"
```

**文件夹结构：**
```
$PROJECT_DIR/
├── assets/           # 素材文件夹（用户可预先投放素材）
├── .slide-design/    # AI 工作文件
│   └── charts/       # 图表数据
└── (其他文件后续生成)
```

### Step 0.2: 告知用户素材投放点

**创建文件夹后，告知用户：**

```
📁 已创建项目文件夹：$PROJECT_DIR/

💡 **assets/ 文件夹是你的素材投放点！**

整个流程中，凡是需要上传文件的地方，你都可以提前放到 assets/ 文件夹里：
   → 📷 Logo/校徽图片
   → 🖼 参考模板截图（如果要用"使用我的模板"）
   → 🖼 背景照片
   → 📊 数据图表原图
   → 📄 现有的 Markdown/Word 大纲
   → 📋 其他参考资料

**好处：**
   → 不用等 Agent 请求上传，可以提前准备
   → 上传功能不顺畅时，有本地投放点
   → Agent 有明确的素材查找位置
```

### 数据可视化处理

> **⚠️ VS Code 插件用户注意：**
> 如果你使用的是 VS Code 插件版的 Claude Code，目前**不支持直接上传 Excel 文件**。
>
> **解决方案：**
> 1. 把 Excel 文件放到本地工作区目录下，告诉我文件路径（如 `./data.xlsx`），我可以用可用的表格工具读取
> 2. 或者把数据导出为 CSV/JSON 格式，粘贴给我
> 3. 或者截图表格/图表，我可以从图片中提取数据

**触发条件：** 用户上传了 Excel/CSV 文件，或文档中包含数据表格/图表

**两种场景：**

| 场景 | 输入 | 处理方式 |
|------|------|----------|
| **从数据生成** | Excel/CSV 原始数据 | 分析数据 → 选择图表类型 → 生成 SVG |
| **美化现有图表** | 文档中的截图/图表 | 提取数据 → 重新渲染 → 生成 SVG |

---

#### Step 1.D1: 数据检测

当用户上传文件时，检查是否包含：
- `.xlsx` / `.csv` → 纯数据文件
- Word/PPT 中的表格 → 嵌入数据
- 图片中的图表 → 需要 OCR 或手动提取

---

#### Step 1.D2: 数据提取

**Excel/CSV：**
```
用 xlsx skill 读取数据
识别：表头、数据类型、数值范围
```

**现有图表（图片）：**
```
用 Read 工具查看图片
识别图表类型（柱状图/折线图/饼图/...）
提取关键数据点
如果无法准确提取，询问用户确认数据
```

**现有图表（Word/PPT 内嵌）：**
```
用 docx/pptx skill 提取
尽可能获取原始数据，而非截图
```

---

#### Step 1.D3: 图表类型推荐

根据数据特征推荐合适的图表：

| 数据特征 | 推荐图表 | 说明 |
|----------|----------|------|
| 分类 + 数值 | 柱状图 / 条形图 | 比较不同类别 |
| 时间序列 | 折线图 / 面积图 | 展示趋势变化 |
| 占比关系 | 饼图 / 环形图 | 展示部分与整体 |
| 多维度对比 | 分组柱状图 | 同时对比多个维度 |
| 相关性 | 散点图 | 展示变量关系 |
| 流程/漏斗 | 漏斗图 / 桑基图 | 展示转化流程 |

**询问用户（header: "图表"）：**
"我发现了一些数据，建议用 [图表类型] 展示，可以吗？"

选项：
- **"可以"** → 使用推荐类型
- **"换个类型"** → 用户指定其他类型
- **"不需要图表"** → 跳过，用文字呈现

  "data": {

  "source": "[用户提供: sales.xlsx]"

#### 图表 SVG 生成（Phase 3 执行）

**在生成 HTML 时，读取 `.slide-design/charts/*.json`，为每个图表生成内联 SVG。**

**SVG 图表优势：**
- 矢量，无限缩放不失真
- 可以用 CSS 控制颜色（符合 VI）
- 文件小，可直接嵌入 HTML
- 支持动画（用 CSS animate path）

**生成原则：**
- 颜色使用 CSS 变量（`var(--color-primary)` 等）
- 字体使用演示稿字体（`var(--font-body)`）
- 简洁现代，去除不必要的装饰
- 数据标签清晰可读

| 来源 | 说明 | 标注格式 |
|------|------|----------|
| **用户提供** | 用户直接输入/上传的内容 | `[用户提供]` |

| **网络搜索** | 补充最新案例、数据、定义 | `[网络搜索]` |

> **注意**：来源标注用于帮助你了解内容来源，确认大纲后会自动清除，最终演示稿只保留干净的内容。
