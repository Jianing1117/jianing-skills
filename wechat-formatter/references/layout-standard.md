# 已确认的公众号排版标准

普通正文参考轻盈的编辑式排版，章节标题和列表保留 Brand Kit。三种文章模板共用以下正文尺度，不把知识类的 CHAPTER 标题套到清单或随笔里。

- 普通正文：Helvetica Neue / PingFang SC / Hiragino Sans GB / Microsoft YaHei / sans-serif，16px、300 字重、近黑 #171717、1px 字距、1.9 行高、段后 28px、两端对齐。仅普通正文及列表文字采用这组参数。
- 标题保留各模板的品牌层级、字体与颜色。知识类 CHAPTER 标签为 11px 展陈蓝 #607EA5，中文标题 22px 加粗，章节块上 72px、下 48px；不改成彩色行内数字标题。标题按当篇语义换行，不复用案例的断行。
- 无序列表使用实际的 • 字符，知识与清单类用天蓝 #B8D9EA，随笔类用樱粉 #E7C4C8；有序编号用展陈蓝 #607EA5。标记大小、间距与模板一致，避免只用会被微信清掉的空 span 画圆点。
- 少量重点按语义选择，保留原文措辞；知识类使用天蓝白 #EBF4F9 底纹与近黑 700 粗体，不把所有正文或所有数字都强调。
- 导出根容器 width:100%、box-sizing:border-box、margin:0、padding:0 20px。水平内缩只加这一层；正文、标题和图片共用内容边线。本地预览外壳不复制上传，不再叠加旧版 44px 边距。以微信原生栏宽减 40px 为正文宽度；390px 屏幕的 350px 原生栏对应 310px 正文，桌面 677px 原生栏对应 637px，仅作验收示例，不硬编码平台栏宽。
- 图片 width:100%、height:auto，按原顺序缩放。不要把阅读页的懒加载占位或运行时固定像素宽度复制回编辑器。
- 文末保留 END、关注文案与品牌卡片。在「欢迎大家关注我的公众号」下紧接一个居中的天蓝色 ☟，字体 Apple Symbols / Segoe UI Symbol / Noto Sans Symbols 2 / serif，36px、行高 1.1、上间距 8px；中间不插入空段或空 section。结尾容器底边距设为 0，避免微信默认段距拉开小手。卡片上间距 24px。用单色符号保持蓝色，不用强制呈现黄色的彩色 emoji。

保存后核对全文、标题与列表、重点、全部图片、文末小手及封面；手机和桌面均检查，不能只凭没有横向溢出就判定边距正确。
